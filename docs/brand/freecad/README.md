# The FreeCAD logo

These two files are the FreeCAD wordmark, copied unchanged from the FreeCAD
Project Association's official logo kit
(https://fpa.freecad.org/images/logos/logo_kit.zip, linked from the brand
guidelines at https://fpa.freecad.org/handbook/process/logo.html):

- `FreeCAD-wordmark.svg`: for light backgrounds
- `FreeCAD-wordmark-light.svg`: for dark backgrounds

The FreeCAD logo is a trademark of the FreeCAD Project Association AISBL
(FPA). Atech AI CAD uses it only to say that the app is built on FreeCAD
and to link to https://www.freecad.org, as the FPA's brand guidelines and the
FreeCAD licence page (https://wiki.freecad.org/License) allow. It is not
Atech's logo and does not mean the FreeCAD project or the FPA endorses Atech
AI CAD. Do not alter these files (colour, shape or effects); use them as
provided.
